# Registro de decisiones de arquitectura

| ADR | Estado | Decisión |
|---|---|---|
| ADR-001 | Aceptado | Monolito Laravel MVC con capa de servicios |
| ADR-002 | Aceptado | Stock materializado más libro inmutable de movimientos |
| ADR-003 | Provisional | El MVP emite comprobante interno, no factura electrónica |
| ADR-004 | Provisional | Una empresa, sucursal y bodega |

Estados permitidos: `Propuesto`, `Provisional`, `Aceptado`, `Reemplazado`, `Rechazado`.

Una decisión provisional puede guiar el desarrollo inicial, pero debe validarse antes de producción. Las preguntas P-001 a P-008 se resuelven creando o actualizando ADR; no se corrigen silenciosamente dentro del código.
