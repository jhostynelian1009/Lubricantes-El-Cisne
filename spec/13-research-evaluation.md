# Plan de evaluación pretest–postest

Este documento define cómo evaluar el efecto del sistema. No contiene resultados; todo valor final debe proceder de observación o medición real.

## Diseño propuesto

Diseño preexperimental de un grupo con medición antes y después de implementar el sistema. La unidad de análisis es el proceso de control de inventario de Lubricantes «El Cisne»; participantes operativos: administrador y empleados autorizados que acepten participar conforme a las reglas académicas aplicables.

## Variable independiente

Aplicación web de gestión de inventario con registro centralizado, movimientos trazables, ventas y reportes.

## Variable dependiente

Control del inventario, observado mediante exactitud, tiempo, incidencias y trazabilidad.

## Indicadores

| Código | Indicador | Fórmula o medición | Unidad |
|---|---|---|---|
| IND-01 | Exactitud del inventario | productos sin diferencia / productos verificados × 100 | % |
| IND-02 | Magnitud de diferencias | suma de diferencias absolutas entre stock físico y registrado | unidades |
| IND-03 | Tiempo de consulta | tiempo desde solicitud hasta identificar stock de una muestra | segundos/minutos |
| IND-04 | Tiempo de reporte | tiempo desde solicitud hasta obtener reporte completo | minutos |
| IND-05 | Errores de registro | omisiones, duplicidades o cantidades incorrectas por período/muestra | conteo |
| IND-06 | Trazabilidad | operaciones muestreadas con actor, fecha, origen y detalle completos / operaciones muestreadas × 100 | % |
| IND-07 | Satisfacción/usabilidad | puntuación de instrumento definido y consistente | escala |

## Instrumentos

- Ficha de observación del proceso actual y del proceso con sistema.
- Hoja de conciliación físico–registrado para una muestra definida de productos.
- Cronómetro y protocolo idéntico para consultas/reportes pre y post.
- Registro de incidencias con criterio previo de qué cuenta como error.
- Cuestionario de usabilidad; si se usa una escala estandarizada, respetar su aplicación y cálculo originales.

## Procedimiento

1. Definir período, productos, participantes y tareas antes de medir.
2. Ejecutar pretest con el proceso actual sin alterar sus condiciones.
3. Registrar valores y evidencia sin completar celdas faltantes por estimación.
4. Implementar y capacitar en el sistema.
5. Establecer un período razonable de uso para reducir el efecto de aprendizaje inicial.
6. Repetir exactamente las tareas del pretest.
7. Comparar valores absolutos y porcentuales, explicando tamaño de muestra y limitaciones.

## Cálculos

- Cambio absoluto: `postest - pretest`.
- Reducción porcentual para tiempos/errores: `(pretest - postest) / pretest × 100`, solo si el pretest es distinto de cero.
- Mejora en exactitud/trazabilidad: `postest - pretest` en puntos porcentuales.

No deben mezclarse porcentajes y puntos porcentuales. Si la muestra es pequeña, se reportan descriptivos y limitaciones; no se afirma causalidad generalizable sin diseño y análisis que la sustenten.

## Evidencia a conservar

- Instrumento vacío y versión aplicada.
- Fechas, participantes codificados y contexto de la medición.
- Datos crudos anonimizados.
- Cálculos reproducibles.
- Capturas o reportes sin datos personales innecesarios.
- Incidencias ocurridas durante las pruebas.

## Amenazas a la validez

- Muestra pequeña y de una sola empresa.
- Aprendizaje de los participantes entre mediciones.
- Cambios de volumen o catálogo entre pretest y postest.
- Conteo físico imperfecto.
- Intervención del investigador durante las tareas.

La discusión del artículo debe reconocer estas limitaciones y no presentar metas del sistema como resultados medidos.
